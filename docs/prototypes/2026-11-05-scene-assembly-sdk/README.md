# 未激活的原生场景装配 SDK 候选

本目录保留在隔离 Core 副本中实现和验证的候选源码，尚未加入正式 Swift Package 或 App。它使用模型生成的部件图、空间计划和几何参数，经原生范围、拓扑、实际几何外包框和资源预算校验后产生现有 SceneSpec；不执行生成的脚本。

隔离测试共68项通过（原47 + 协议/几何10 + 协调器11），见 candidate-validation.json。该记录只证明纯Swift协议与协调器，不证明模型能正确规划任意物体。

同一模型的五题材全新三阶段测试尚未达到质量目标，见 ../../qa/2026-11-05-native-structured-generation/fresh-three-stage-fivecase/README.md。不能因此把候选接入发版流程或宣称通用建模完成。保留多根场景、任意数值偏移与原有全部自由几何上限，具体原型差异见 DRAFT-NOTES.md。

用于继续开发时，将这里5个新增Swift源码/测试与相应基础Core版本一同检查，再在独立副本运行测试。这里没有模型权重或App构建产物。
