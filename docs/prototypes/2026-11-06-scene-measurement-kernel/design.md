# 显式尺寸变量与真实几何测量：隔离设计

这是独立纯 Swift SDK 原型，依赖仓库正式 `Apple/Packages/CreationCore`，不修改正式 Core、App 或已冻结尺度原型。输入已是类型化意图，不读取自然语言、JSON、表达式或脚本。

每个节点完整保留原有形状、位置、旋转、材质、自由几何和连接数据；仅 width/height/depth 改为 `.literal(Float)` 或 `.variable(String)`。输入恰有一个约束：变量名、有限正标量区间，以及某节点某轴的最大坐标或整个场景某轴的包围框跨度与目标米数。同一变量可出现在多个尺寸字段，实现显式等值关系；未引用变量、其它变量名、重复 ID、缺失引用或坏拓扑均拒绝。没有按节点名或物体题材推断关系。

求解器在每个候选标量处，仅代入声明的变量；调用正式 `SceneAttachmentResolver.resolve` 和 `SceneGenerator.generate`，以实际旋转、自由形状、连接重叠与统一落地后的 Float 网格测量。生成路径保留正式的尺寸域、位置域、拓扑校验及 32 部件、20k 顶点、80k 索引等资源预算。原始尺寸草案和其它字段不原地修改。返回代入后的声明场景与单独的 canonical 测量场景，区分求解器变更与原有连接/落地行为。

有限采样不能证明全局单调。本原型采用更窄的**端点夹逼求一个根**合同：固定形状拓扑、位置、旋转与连接，合法域内连续几何度量允许二分；不宣称单调、唯一或找到所有根。端点必须给出相反残差或唯一一个端点已达标；两端均达标按欠约束拒绝。无夹逼即拒绝，即使区间内部可能另有解。固定拓扑的 AABB max/min 和连接操作可分段变化；任何实际评估失败立即终止，不能据端点有效宣称整个区间已被完整验证。

二分最多默认 32 次、配置上限 64 次。每次使用 Float 可表示的中点并检查取消；不能再分、无夹逼、非有限边界、无效 Core 几何或迭代耗尽都抛错。返回前独立重新评估同一候选，实际测量绝对误差必须不大于 **0.001 m**。这只确认一个合法候选的测量，不保证变量精度、工程测量精度或任意多变量方程求解。不会全局缩放、修复 raw 输出、放宽 Core 边界或补默认物体。

比较过按名猜测高度、全局缩放以及通用多变量求解；前两者会改动未授权字段，后者超出本合同，均不采用。验证使用合成几何，包含总跨度、指定节点表面、共享变量、旋转、自由形状、多根、非单调函数的单根/无夹逼、无解、非法输入、资源与取消；合成成功不算 AI 建模成功。App/神经网络接入与产品验收另计。
