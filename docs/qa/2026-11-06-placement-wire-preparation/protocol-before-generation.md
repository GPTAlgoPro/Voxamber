# General placement wire — preparation only

No model batch is authorized or started by this preparation. The production `SceneGenerationSchema`, decoder, generator and App remain unchanged. A new ignored helper (`Apple/.build/placement-wire-helper`) derives a future-generation schema from the full authoritative schema; a new ignored runner (`Apple/.build/placement-wire-five-runner`) keeps the existing sampler/model/prompt/native pipeline.

The only proposed inference variable relative to the sampling+schema condition is the **generation wire's placement requirement**: `nodes.prefixItems[0]` preserves all original 24 primitive/placement alternatives; subsequent `nodes.items` permits the original 16 alternatives whose required fields include either explicit `origin` or `attach`. The first node may still use any original placement. There is no ID/topic logic, no shape template and no response coordinate insertion. Model output must supply its own placement choices; explicit zero origins remain legal and can still produce overlapping bad scenes.

All eight primitives, 32 nodes, 64 profile points, 1024 vertices, 2048 triangles, fields, numbers/materials/rotations, multiple absolute roots, optional data and source floating bounds are preserved. The original `$defs` and each original node alternative are reused intact. No extra geometry/camera change or native postprocessing is introduced.

This changes the contract for **new generation**, not Core legacy decoding. Some old documents with multiple implicit roots remain accepted by unchanged Core but are intentionally not accepted by the new schema. They are not rewritten or relabeled as valid new-wire output. Unit fixtures are isolated synthetic contract data, not old model-output repair or restored user projects.

Zero-origin equivalence is conditional. If the first node remains an implicit root, its existing grounding marker still triggers global grounding; making a following root's zero center explicit can preserve the same geometry. If the first node is explicit and the last implicit marker is removed, existing Core may stop global grounding: blindly adding zero origins is **not** an unconditional canonical equivalence. Complete expressiveness is tested by resolving the old scene through original Core and validating its actual canonical `ScenePlan.snapshot` (explicit actual centers) against the new schema and unchanged Core. This test proves representation, not a runtime migration step.

The CPU-only unit/standard JSON Schema checks cover 24/16 variants, all retained resources and full caps, arbitrary identifiers, multiple roots, conditional zero-origin equality, the grounding counterexample, canonical round trips and exact native mesh buffers. The helper only writes schema, never edits model responses.

If Root later authorizes a batch, keep the same one-load/five-call robot/lamp/whale/aircraft/chair requests and predeclared rubric, sampling bundle/seed24301, no current scene, 3072 tokens, prefill128, KV8192, early JSON stop, same-call raw and native validation. No retry, repair, sixth edit, parameter fallback or old response reuse is permitted. This preparation does not run that future batch. No topology, placement or visual quality improvement is presumed.
