# 本固定种子的采样候选不予接入

Root 已分别查看真实机器人 USDZ 的前视与斜视图，核对实际节点尺寸，详见 [视觉检查](root-visual-review.json)。头的尺寸为 0.36×0.25×0.18m，最大最小边比为 2，违反预先声明的立方体头要求。原始素材未改；不靠额外添加手臂姿态规则来判失败。

本条件五题均形成完整 JSON，长度截断从原贪心基线的两例降到零；但只有机器人能经严格 Core 校验并导出，它仍未满足完整题材要求。其余四例缺少或包含不符合合同的字段，没有修补后再生成替代资产。

结果为本批完整要求 0/5、原生导出 1/5；控制批分别为 1/5、2/5。只能说明在这一固定种子下，整组采样参数改善了 JSON 完整性，未改善实际建模验收。不据此切换正式 App，也不将差异单独归因于 presence 参数。

采样建议来源：[Qwen3.5-4B 官方说明](https://huggingface.co/Qwen/Qwen3.5-4B#best-practices)。实现针对生成历史的解释参照 [vLLM presence 定义](https://docs.vllm.ai/en/latest/api/vllm/sampling_params/)，未声称不同后端的数值结果完全相同。单种子、固定顺序的有限实验不构成统计成功率或 iPhone 性能证明。
